# Code de conduite

Le projet doit rester un espace d’apprentissage accueillant pour les personnes qui utilisent Python, discord.py et Components V2.

## Comportements attendus

- Traiter les autres avec respect et patience.
- Accueillir les questions de débutants sans moquerie.
- Expliquer les désaccords de façon constructive.
- Accepter les corrections de bonne foi.
- Garder les échanges centrés sur le sujet.

## Comportements inacceptables

Les insultes, le harcèlement, les attaques personnelles, les discriminations, les menaces, la divulgation d’informations privées et le spam ne sont pas acceptés.

## Signalement

Un comportement problématique peut être signalé au mainteneur via son [profil GitHub](https://github.com/6bq2). Les signalements seront examinés avec discrétion. Selon la situation, le mainteneur pourra demander la modification ou la suppression d’un contenu, ou limiter la participation.
