# Sécurité et signalement

Ce dépôt contient principalement de la documentation et des exemples. Ne publiez jamais de secret dans une Issue ou une Pull Request.

## Secret publié par erreur

Si un token Discord ou une clé d’API a été exposé :

1. Révoquez-le immédiatement depuis le service concerné.
2. Générez un nouveau secret.
3. Vérifiez les commits et les logs où l’ancien secret a pu apparaître.
4. Ne vous contentez pas de supprimer le secret du dernier commit : considérez-le comme compromis.

## Signaler une vulnérabilité

N’ouvrez pas d’Issue publique avec des détails exploitables. Contactez le mainteneur via son [profil GitHub](https://github.com/6bq2) et fournissez uniquement les informations nécessaires à l’analyse.

Les erreurs de rédaction ou les exemples incorrects sans impact de sécurité peuvent être signalés dans les [Issues du dépôt](https://github.com/6bq2/discord.py-CV2-fr/issues).
